

# Accessory Scripts

These are scripts that are optional and NOT part of the pipeline. They can be used after a pipeline runs to: 

1. Verify outputs and assemble an overview stats file of the run 
2. Update RmarkdownA (Main Menu HTML page) and/or RmarkdownB (Metadata page) as needed without having to rerun the entire pipeline again
3. Consolidate the outputs of runs across different samples for big picture analysis

Please check the respective folders for further details
